모델은 데이터의 품질만큼만 똑똑해집니다(Garbage in, garbage out). 비어 있거나 튀는 값을 정리하고, 크기가 다른 속성을 같은 범위로 맞춥니다.

기계학습 이 단계에서 필요한 내용

결측치 (missing value)

값이 비어 있는 칸. 비율이 적으면 행 삭제, 많으면 평균/중앙값/최빈값으로 대체(삭제하면 데이터 손실이 커짐)

이상치 (outlier)

다른 값과 동떨어진 값. 산점도·상자그림으로 찾고 IQR 규칙으로 범위를 정함
최솟값 = Q1 − 1.5×IQR, 최댓값 = Q3 + 1.5×IQR (IQR = Q3 − Q1). 속성 의미에 따라 조정(시간은 음수 불가 → 0)

정규화 (normalization)

속성마다 단위·크기가 달라(운동 0~240분, 수면 3~10시간) 거리 기반 모델(kNN, SVM)이 큰 값에 끌려감 → 0~1 범위로 맞춤
x' = (x − 최솟값) / (최댓값 − 최솟값)

기계학습 이 단계에서 필요한 내용

분포 (Distributions)

값이 어느 구간에 많이 모여 있는지(히스토그램). 치우침·빈도·이상치를 확인하여 데이터의 특징을 문장으로 설명합니다.

상관계수 (Pearson r)

−1 ~ 1. 부호는 방향(+: 함께 증가, −: 반대로 변화), 크기는 강도.
|r| ≥ 0.7 강함 · 0.4~0.7 중간 · 0.2~0.4 약함 · 0.2 미만 거의 없음
⚠ 상관관계 ≠ 인과관계

분석에 사용한 데이터는 특정 집단(우리 학교 학생 등)에서 수집한 것이므로 결과를 모든 청소년에게 일반화하는 데는 한계가 있어요.

훈련 데이터 vs 테스트 데이터

모델은 훈련 데이터(70%)로 학습하고, 한 번도 보지 못한 테스트 데이터(30%)로 실력을 확인합니다. 시험 문제를 미리 보고 공부하면 실력을 알 수 없는 것과 같아요.

재현 가능한 샘플링

Data Sampler는 무작위로 나누므로 실행할 때마다 결과가 달라질 수 있습니다. Replicable (deterministic) sampling을 체크하면 같은 결과가 나옵니다. 분류 문제에서는 Stratify sample로 클래스 비율을 유지하세요.

어떤 모델이 가장 잘 예측할까?

Test and Score로 여러 모델의 성능 지표를 비교하고, 결과를 해석하여 문제 해결 방안과 한계를 정리합니다.

기계학습 이 단계에서 필요한 내용

회귀 모델 지표 (target이 숫자)

  • MSE 평균 제곱 오차: (실제−예측)²의 평균 → 작을수록 좋음
  • RMSE = √MSE: target과 같은 단위의 평균 오차
  • MAE 평균 절대 오차: |실제−예측|의 평균
  • R² 결정 계수: 모델이 설명하는 변동의 비율, 1에 가까울수록 좋음 (0 이하면 평균으로 찍는 것보다 못함)
  • MAPE는 실제값이 0에 가까우면 매우 커지므로 정규화 데이터에서는 해석에 주의

분류 모델 지표 (target이 범주)

  • CA 정확도: 맞힌 비율
  • Precision 정밀도: ‘A’라고 예측한 것 중 실제 A의 비율
  • Recall 재현율: 실제 A 중 A라고 맞힌 비율
  • F1: 정밀도와 재현율의 조화 평균
  • 혼동 행렬: 어떤 범주를 어떤 범주로 헷갈렸는지

교차 검증 (Cross validation)

훈련 데이터를 k개(예: 5개)로 나누어 한 조각씩 돌아가며 시험용으로 쓰고 평균 성능을 냅니다. 데이터가 적을 때 한 번의 분할 운에 좌우되지 않게 해 줍니다. 오렌지 Test and Score의 기본 방식입니다.

  1. Evaluate Test and Score를 추가 → Data Sampler(Data Sample)와 4개 모델(Learner)을 모두 연결
